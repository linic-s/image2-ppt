# image2-ppt

先选择视觉风格，再逐页生成带文字的幻灯片图片，最后还原为可编辑、带动画的 PowerPoint。

这是供 AI 助手执行的 Skill。使用者需要在运行环境中配置图片生成和 PPT 制作能力。仓库提供流程指令，不附带模型服务、API 额度或独立应用程序。

## 制作流程

1. **接收资料与主题。** 阅读论文、数据、笔记或已有演示文稿，整理逐页内容。
2. **生成三款样例。** 用同一页内容展示三种视觉设计，等待用户选择。
3. **逐页生成图片。** 沿用选定风格，每次生成一张完整幻灯片，检查文字与图表后保存。
4. **逐页还原 PPT。** 全部图片完成后，依次重建文字和图表，保留复杂插画素材。
5. **添加动画并交付。** 按讲解顺序安排内容入场，检查最终文件，交付 PPT、图片与制作源文件。

已选择风格的任务可以继续制作。每个项目记录完成进度，中断后可接着处理未完成页面。

## 运行要求

当前指令面向能够读取本地 Skill 和操作文件的 Codex 环境，依赖下列能力：

| 能力 | 用途 |
| --- | --- |
| `imagegen` Skill 与图片生成工具 | 生成风格样例、完整页面及局部修正 |
| `presentations` Skill 与 PPTX 制作、渲染工具 | 创建可编辑幻灯片并检查版式 |
| 原生 PowerPoint 动画支持 | 为内容对象设置入场效果，检查动画目标 |
| `ppt-master`（可选） | 补充图片还原和动画处理能力 |

上述依赖须由运行环境提供或另行安装。缺少图片工具时，流程不会悄悄改用需要付费密钥的 API。没有可用的动画实现时，会说明未完成的步骤。

名称中的 `image2` 表示图片优先的制作流程。实际模型取决于当前图片生成工具；本技能不强制某个供应商或模型版本。

## 安装

在 GitHub 仓库页面选择 **Code → Download ZIP**，解压后将包含 `SKILL.md` 的目录命名为 `image2-ppt`，放入自己的 Codex 技能目录：

```text
~/.codex/skills/image2-ppt/
```

如果设置了 `CODEX_HOME`，则放入该目录下的 `skills/image2-ppt/`。Windows 用户也可以在用户目录中找到 `.codex/skills`。

安装后的目录结构：

```text
image2-ppt/
├── SKILL.md
├── agents/
│   └── openai.yaml
├── references/
│   └── reconstruction-and-motion.md
├── README.md
└── LICENSE
```

## 调用示例

```text
使用 $image2-ppt，根据附件论文和数据，制作一份 12 页的课题答辩 PPT。
先给我三款不同风格的样例，等我选择后再制作全部页面。
```

```text
选择 B 风格。请逐张生成全部页面图片，再逐页还原成可编辑 PPT，
添加适合现场讲解的动画，同时保留按页编号的图片和制作源文件。
```

需要保留特定版式、页数、原题选项或输出路径时，可以在请求中直接说明。只需要图片时，明确说“只交付逐页图片”，流程将在图片阶段结束。

## 交付范围

默认交付带动画的 `.pptx`、按顺序编号的单页图片，以及内容大纲、风格说明、生成提示词和实际制作源文件。

文字和支持的图表会重建为可编辑对象，复杂插画可作为图片保留。整页图片版需要用户明确选择。不同 Office 应用的字体和渲染表现可能有所差异，成品需要逐页对照检查。

图表数值须来自提供的资料。生成图片后还要核对文字、比例和标注；图片生成不能替代数据计算。
